# 兔子动画打包说明

本文记录 `jingling` 兔子外观如何从 PNG 和 Spriter SCML 源文件，编译为饥荒联机版可加载的 `anim/jingling.zip`。

## 前置条件

- 已通过 Steam 安装 **Don't Starve Mod Tools**。
- 已确认工具目录中存在 `mod_tools\scml.exe`。
- 工作区中的 `game-mod/anim_source/jingling` 是源文件，`game-mod/anim/jingling.zip` 是必须随 Release 发布的编译产物。

## 项目内源文件

兔子动画源文件位于：

```text
game-mod/
  anim_source/jingling/
    jingling.scml
    jingling_front.png
    jingling_left.png
    jingling_right.png
    jingling_back.png
    jingling_blink.png
```

- `jingling.scml`：Spriter 动画描述，定义 `idle`、`walk_loop` 等动画。
- PNG：每个动画帧使用的图片。图片需要带透明通道。

## 为什么不能只把 PNG 放进 Mod

DST 实体动画不能直接加载 PNG。PNG 必须由 Klei 官方 Mod Tools 编译，得到含 `anim.bin`、`build.bin` 与纹理数据的 ZIP。最终 ZIP 需要放在 Mod 的 `anim/` 目录，并在 `modmain.lua` 中注册：

```lua
Assets = {
    Asset("ANIM", "anim/jingling.zip"),
}
```

## 编译步骤

推荐直接调用 `scml.exe`。编译器要求 SCML 与 PNG 位于已安装 Mod 的 `exported/<动画名>/` 下，并把结果写入该 Mod 的 `anim/`。

在 PowerShell 中执行：

```powershell
$projectRoot = "F:\game\dsh-xiaotangyuan-game\games\dont-starve-together"
$source = Join-Path $projectRoot "game-mod\anim_source\jingling"
$dstRoot = "E:\steam\steamapps\common\Don't Starve Together"
$modTools = "E:\steam\steamapps\common\Don't Starve Mod Tools\mod_tools"
$modRoot = Join-Path $dstRoot "mods\dont-starve-ai-mod"
$export = Join-Path $modRoot "exported\jingling"

New-Item -ItemType Directory -Force -Path $export | Out-Null
New-Item -ItemType Directory -Force -Path (Join-Path $modRoot "anim") | Out-Null
Copy-Item -LiteralPath "$source\jingling.scml" -Destination $export -Force
Get-ChildItem -LiteralPath $source -Filter "*.png" |
  Copy-Item -Destination $export -Force

& "$modTools\scml.exe" "$export\jingling.scml" $modRoot
if ($LASTEXITCODE -ne 0) {
  throw "Jingling animation compilation failed."
}
```

成功时会显示 `Exporting Animation` 和 `Atlasing`，最终文件为：

```text
<DST>\mods\dont-starve-ai-mod\anim\jingling.zip
```

## 回写到项目

为使项目保留可发布的成品，将生成的 ZIP 回写到工作区：

```powershell
Copy-Item `
  -LiteralPath "$modRoot\anim\jingling.zip" `
  -Destination "$projectRoot\game-mod\anim\jingling.zip" `
  -Force
```

最后运行正式验证与打包：

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
.\scripts\build-player-package.ps1
```

构建会拒绝缺少 `anim.bin` 或 `build.bin` 的错误动画包。随后用新生成的安装器覆盖安装，重启游戏并进入世界测试；只到标题界面不足以验证宠物外观。

## 修改动画后

每次修改任一 PNG 或 `jingling.scml` 后，重复“编译步骤”和“回写到项目”。不要手动解压或修改最终 ZIP；应始终以 PNG/SCML 为源文件重新编译。
