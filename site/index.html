GETTING STARTED

从关注项目，到真正进入游戏

目前仍是开发验证阶段，还没有面向普通玩家的正式签名安装包。我们会把安装、选择游戏和进入游戏的过程收敛成一个应用。

01

关注测试进展

先通过小红书、QQ 群或 GitHub 查看最新验证结果和可用范围。

02

安装一个应用

正式版本会统一管理模型配置、语音能力和不同游戏的安装包。

03

选择自己的游戏

只下载需要的游戏内容，不必一次安装所有游戏的组件和 MOD。

04

进入游戏开始陪伴

通过文字或语音交流，让 AI 根据当前存档和真实局面作出回应。

当前状态v1.1.0 已提供稳定源码，Windows 一键安装包仍在准备中。自动测试和本地安装验证不等于真实游戏长期体验已经完成。
