WHY THIS HARNESS

把时间留给玩法，
不是重复接 AI API

通用能力由统一运行时提供；每款游戏只维护自己的世界知识、状态、动作和原生 API 边界。

01
CORE

复用完整 Agent 主链

模型选择、Session、Tool Calling、凭据、权限和流式回复不需要在游戏 Mod 中重新实现。

02
MEDIA

复用视觉与语音

窗口截图、麦克风、ASR、TTS 和流式播放由桌面运行时统一管理，游戏侧不保存第三方 Key。

03
STATE

游戏事实保持权威

AI 可以提出行动，但动作是否成功、任务是否完成，必须由 Adapter 返回的新状态证明。

04
PACK

按游戏独立发布

知识、内容、Adapter 和薄 Bridge 组成 Game Pack，按需安装、升级和卸载，不把所有游戏打进核心。

PRODUCT DOCTRINE

不是把聊天框塞进游戏，
而是建立可信的 AI 游戏边界

Harness 负责通用 AI 运行时和游戏领域编排，Adapter / 薄 Mod 负责连接原生 API，游戏本体始终拥有事实与最终执行权。

P / 01

复用 DSH 通用运行时

模型、Agent、Tool、Session、配置、凭据、权限和插件生命周期沿用 DSH；项目集中解决游戏领域问题，不重复造一套 Agent Runtime。

P / 02

游戏能力首先插件化

记忆、语音、视觉、UI、安装、Transport 和每游戏语义工具遵循插件生命周期，可以独立启停、替换和测试。

P / 03

游戏 Mod 必须薄

Mod 只上报真实状态与事件并封装原生动作；不调用模型、不负责规划，也不保存 Harness 记忆。

P / 04

事实先于模型推测

视觉用于理解，模型用于决策和表达；物品、任务、金钱、死亡和地图变化必须由游戏 API 返回确认。

P / 05

界面是一等产品能力

对话、权限、记忆、动作结果和诊断共同构成可信体验，不能只在后台留下无法理解的日志。

P / 06

版本固定，升级可验证

Runtime、插件、Game Pack 和 Bridge 协议都有明确兼容范围；升级先过 Fake Game、协议测试和真实存档验收。

P / 07

替换基础能力必须先举证

接口可以替换，不代表应该重写。只有可复现测试证明 DSH 的具体能力无法满足游戏需求时，才建立最小替代，并继续保持模型与插件边界可换。

THREE STEPS

三步接入一款游戏

先从最小闭环开始：观察一个真实状态，执行一个确定动作，再让游戏返回结果和新状态。

1

描述世界与能力

定义 gameId、状态 Schema、可执行动作、事件和权限范围。

2

实现 Game Adapter

把 Harness 的观察和动作请求翻译成游戏 API；必须进程内执行的部分放进薄 Native Bridge。

3

打包并通过一致性检查

组合 Game Pack，运行 Mock Game、Adapter conformance 和真实存档闭环。

ONE GAME · ONE GAME PACK

不同游戏按需加载，不塞进核心

Game Pack 是一款游戏完整的 AI 接入与发行单元。用户只安装自己需要的游戏，开发者也能单独版本化、升级和卸载。

PLUGINHarness Plugin知识、Schema、语义工具与编排
CONTENT角色与剧情配置世界观、允许目标、禁写事实与节奏
BRIDGEAdapter / Mod状态、事件、原生动作和权威回执
MANIFEST安装与兼容信息版本、权限、校验和、路径与卸载记录

TWO PROTOCOLS

插件协议与线协议，
解决不同的问题

Harness 内部能力装配和跨进程调用不能混成同一个概念。游戏 Mod 不需要理解 TypeScript、Cordis 或模型厂商。

INSIDE HARNESS

DSH / Cordis Plugin Protocol

管理 Game Core、Memory、Media、UI、Installer、Transport 和每游戏 Harness Plugin 的依赖注入、事件和可逆生命周期。

  • 复用同一个 Agent Session
  • 插件可独立装配和停用
  • 凭据不进入游戏 Mod
ACROSS PROCESSES

Native Bridge Contract

面向 C#、Lua、C++ 等不同游戏环境，只传递游戏身份、能力、Observation、Event、Action、Result、revision 和错误。

  • 稳定、版本化的 JSON 消息
  • WebSocket 只是默认 Transport
  • 不传 Provider Key 和隐藏推理
HARNESS OWNS

我们负责

  • 完整打包并复用通用 AI Runtime
  • 标准游戏插件与可独立安装的 Game Pack
  • 跨语言、可测试的 Native Bridge Contract
  • 基于真实状态的动作回执和 Trace
  • 本机优先的权限、记忆与隐私边界
NON-GOALS

我们不负责

  • 不重写已有模型、Agent、Tool 与 Session
  • 不要求游戏 Mod 使用 TypeScript 或 Cordis
  • 不把规划、记忆和模型调用塞进 Mod
  • 不取代 Unity、Godot 或游戏运行时
  • 不让远程模型控制逐帧战斗和寻路
